# LLM Wiki

Karpathy-style knowledge base for LLM research, projects, and learnings.

## Structure

- `MOCs/` — Maps of Content (index pages linking related notes)
- `concepts/` — Atomic notes on individual concepts
- `projects/` — Project-specific documentation
- `infrastructure/` — Setup guides, tooling, and configuration
- `sessions/` — Daily session logs
- `templates/` — Note templates

## Sync

This wiki syncs across:
- **Obsidian** (Windows Desktop) via Obsidian Git plugin
- **VPS** via cron job
- **Claude Code / Cursor** via enquire-mcp
